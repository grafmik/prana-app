# PRANA — version navigateur (branche `web`)

Le jeu tel qu'il est en ligne sur **https://prana.9mp.org/** : `site/` est la sortie de `tools/build_web.sh` (dépôt du
jeu, privé). Le VPS récupère cette branche et sert `site/` (Coolify, app `prana`). Ne pas éditer à la main :
`tools/publish_web.sh` la remplace à chaque version. Versions Mac et Android : https://9mp.org/prana/
