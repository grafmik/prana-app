# PRANA — téléchargements

Les versions publiées de **PRANA, un voyage fractal en transe**, pour Mac et Android.

**Page de téléchargement : https://9mp.org/prana-app**

Ce dépôt ne contient que les fichiers des versions (onglet *Releases*) ; le code du jeu vit dans un autre dépôt.

| Fichier | Pour |
|---|---|
| `PRANA-mac.zip` | Mac Apple Silicon ou Intel, macOS 12 ou plus récent. App non notarisée : la page explique comment l'ouvrir. |
| `PRANA-android.apk` | Android 10 ou plus récent, téléphone 64 bits avec Vulkan. Signée par le dépôt F-Droid « 9mp Apps » (https://fdroid.9mp.org/fdroid/repo), qui apporte les mises à jour automatiques. |

Les liens `releases/latest/download/PRANA-mac.zip` et `releases/latest/download/PRANA-android.apk` donnent toujours la dernière version.
